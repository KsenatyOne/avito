# Объявления Авито

Готовь массовые названия и описания по шаблону и исходным данным пользователя. Источник правил — [снимок правил Авито](references/avito-rules.pdf), предоставленный пользователем: это изображение страницы автозагрузки с выбранным типом товара «Другое», а не универсальная схема всех категорий. Перед заполнением любых полей кроме названия и описания сверяй соответствующий раздел PDF и актуальный шаблон выбранной категории; не считай примеры значений полным списком. Правила площадки и доступные категории могут измениться.

## Порядок работы

1. Получи шаблон, исходные товары, требуемое количество вариантов и формат результата. Сохраняй связь каждой строки с исходным товаром или его идентификатором. Если фактов недостаточно, обозначь пробелы и запроси необходимые данные; не выдумывай характеристики, наличие, гарантии, цену или условия доставки.
2. Для каждого товара создай релевантное название и читабельное описание по предоставленному шаблону. Варианты должны отражать факты конкретного товара, без искусственного набора ключевых слов и неподтверждённых обещаний.
3. Название `Title` обязательно, не более 50 символов; не включай цену, контакты и слово «продам».
4. `Description` — не более 7500 символов. Используй HTML по просьбе пользователя: только `p`, `br`, `strong`, `em`, `ul`, `ol`, `li`. Проверяй корректность вложенности и отсутствие других тегов и атрибутов. PDF оговаривает, что форматирование доступно для объявлений, соответствующих оплаченному тарифу; если это неизвестно, сообщи об условии и не утверждай, что оформление точно отобразится.
5. Для XML помести HTML внутри `<![CDATA[...]]>` в `Description`. Внутри CDATA не экранируй `<`, `>` и `&` XML-сущностями; последовательность `]]>` завершает CDATA и не должна встречаться внутри неё. Переводы строк преобразуются в `br`, поэтому избегай лишних переносов между HTML-блоками. Для таблицы помещай HTML непосредственно в ячейку описания, без XML-обёртки, если шаблон не требует иного.
6. Если закон требует специальных предупреждений для конкретных сведений или товара, включи соответствующее предупреждение на основе проверенной информации. Не устанавливай применимость документов или маркировки без подтверждения.
7. Проверь каждую строку: длину названия и описания, теги, фактическую точность, соответствие шаблону и идентичность товара. Сообщи о пропусках и неподтверждённых условиях отдельно от готовых текстов.

Пример фрагмента XML (факты условные):

```xml
<Description><![CDATA[<p><strong>Настольная лампа</strong> в рабочем состоянии.</p><ul><li>Цвет: белый</li><li>Материал: металл</li></ul>]]></Description>
```

## Если требуется полный файл автозагрузки

Не представляй одни названия и описания как готовый файл. Сверь все обязательные и условные поля выбранной категории с актуальным шаблоном и PDF. В снимке для XML указаны UTF-8, максимум 50 000 объявлений, корневой `Ads` с атрибутами `target="Avito.ru"` и `formatVersion="3"`, вложенные `Ad`, чувствительные к регистру латинские имена параметров. Идентификатор `Id` должен быть уникальным и стабильным между загрузками. Не придумывай идентификаторы существующих объявлений и не меняй их без основания. Для снимка категории «Другое» проверь в том числе адрес, фотографии, цену, вид объявления, состояние и страну происхождения по соответствующим разделам. Платное продвижение и настройки расходов не включай без явных указаний пользователя. Проверяй XML парсером и не публикуй объявления без отдельного поручения.
